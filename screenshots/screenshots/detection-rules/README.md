# Custom SIEM Detection Rules

This folder contains documentation for three custom security detection rules configured in Kibana.

## Detection Rules

1. **Multiple Failed Login Attempts** — Monitors repeated Windows authentication failures using Event ID 4625. Alert generation was successfully verified.

2. **DNS Tunneling Detection** — Investigates suspicious DNS activity. Rule configured; successful alert generation has not yet been verified.

3. **PowerShell Exploitation Detection** — Investigates potentially suspicious PowerShell execution. Rule configured; successful alert generation has not yet been verified.

## Purpose

These detection rules were developed as part of an ELK SIEM cybersecurity internship project to improve security event monitoring and investigation capabilities.
